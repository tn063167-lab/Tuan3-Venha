## Mục tiêu thực hiện Lab 07
- Điều khiển cách các phần tử hiển thị trong document flow và thay đổi bằng thuộc tính `display`.
- Định vị phần tử bằng relative và absolute positioning; kiểm soát thứ tự chồng lớp bằng `z-index`.
- Sử dụng `float` và `clear` để bố trí phần tử và xử lý nội dung bao quanh.
- Xây dựng bố cục nhiều cột bằng float và positioning.
- Thiết kế giao diện responsive bằng media queries và viewport.
- Sử dụng CSS transforms, transitions, filters và animations.
- Ứng dụng Bootstrap grid system và các thành phần giao diện có sẵn.
