Exercise 8.1 – Enabling/Disabling JavaScript

Trang này tự kiểm tra trình duyệt hiện có bật JavaScript hay không (tương tự trang JavaScriptTest.php mà bài Lab yêu cầu truy cập).

Cách bật/tắt JavaScript

  • Chrome / Edge: Settings → Privacy and security → Site settings → JavaScript → chọn Don't allow sites to use JavaScript.
  • Firefox: gõ about:config → tìm javascript.enabled → đặt false.
  • Hoặc dùng DevTools: Ctrl+Shift+P → gõ Disable JavaScript.

Sau khi tắt, tải lại trang (F5): thông báo sẽ chuyển sang màu đỏ “You have JavaScript disabled”. Có thể so sánh với trang gốc của giáo trình: examples.funwebdev.com/JavaScriptTest.php.
