Lab 08

JavaScript 1: Language Foundations

Làm quen với cú pháp JavaScript, biến, kiểu dữ liệu, hàm, đối tượng, mảng và Browser Console.

Danh sách Exercise (12)

8.1 Enabling/Disabling JavaScriptKiểm tra trình duyệt bật/tắt JavaScript; dùng thẻ noscript. → 8.2 Embedded JavaScriptNhúng script trực tiếp vào thẻ head, hiển thị hộp thoại alert(). → 8.3 External JavaScriptNạp file hello.js bên ngoài và dùng document.write(). → 8.4 Using noscriptHiển thị nội dung dự phòng khi JavaScript bị tắt. → 8.5 Using the Browser ConsoleTổ chức thư mục js/, đọc lỗi trong Console, dùng console.log/warn/error. → 8.6 Built-in JavaScript ObjectsString (literal và object), Date, Math, toán tử == và ===. → 8.7 Arrayspush(), unshift(), vòng lặp for và bảng lịch 30 ngày. → 8.8 JavaScript FunctionsHàm, tham số, giá trị trả về và phạm vi biến (scope). → 8.9 Functions as ObjectsHàm lồng nhau, hàm ẩn danh, truyền hàm làm tham số (tính giá trị giỏ hàng). → 8.10 Creating JavaScript ObjectsObject literal, constructor function, phương thức total() và output(). → 8.11 Arrays of ObjectsMảng đối tượng Country, vòng lặp for..in, cờ quốc gia. → 8.12 Hands-on: Travel postsThay danh sách HTML viết tay bằng hàm JavaScript từ dữ liệu travel-data.js. →
