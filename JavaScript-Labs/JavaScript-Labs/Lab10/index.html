Lab 10

JavaScript 3: jQuery

Dùng jQuery để chọn phần tử, xử lý sự kiện, thao tác DOM, tạo hiệu ứng và gửi GET request.

Danh sách Exercise (10)

10.1 Set up jQueryNạp jQuery từ CDN và bản dự phòng cục bộ. → 10.2 Basic SelectorsBộ chọn #id, tag, .class; val(), html(), attr(), css(), addClass(). → 10.3 Advanced Selectors:password, :nth-child(4n), :contains(). → 10.4 jQuery Listenersclick, on(), document ready, chaining, off(). → 10.5 Inserting DOM Elementsafter, before, append, prepend, appendTo, prependTo, insertBefore. → 10.6 Simple jQuery AnimationfadeIn/Out/Toggle và slideUp/Down/Toggle. → 10.7 More jQuery AnimationPopup xem trước ảnh lớn khi rê chuột, mousemove/mouseleave. → 10.8 Complex Animationsanimate() với nhiều thuộc tính CSS và hiệu ứng nối tiếp. → 10.9 GET Requests$.get() gọi web service JSON và hiển thị danh sách thành phố. → 10.10 jqXHR Handlingdone(), fail(), always() và ảnh loading. →
